글 제목 아래와 글 목록 카드의 날짜 옆에 시계 아이콘과 함께 예상 읽기 시간이 표시됩니다. 따로 적을 것은 없고, 빌드할 때 본문 길이로 계산됩니다.

## 계산 방식

- 한글은 글자 수를 세어 1분에 500자로 계산합니다.
- 영어 같은 다른 언어는 단어 수를 세어 1분에 200단어로 계산합니다.
- 두 값을 더해 반올림하고, 1분보다 짧으면 1분으로 표시합니다.

코드블록, 수식, 다이어그램 원문도 본문에 포함해서 셉니다. 대략적인 값이므로 실제 읽는 시간과는 차이가 있을 수 있습니다.

## 속도 바꾸기

읽기 속도는 `src/utils/readingTime.ts` 맨 위의 두 값으로 정합니다.

```ts file="src/utils/readingTime.ts"
const HANGUL_PER_MINUTE = 500;
const WORDS_PER_MINUTE = 200;
```
