---
title: Frontmatter 예시
description: 글 맨 위 frontmatter에 쓸 수 있는 항목과 각 항목이 하는 일
pubDatetime: 2026-10-12T01:00:00+09:00
category: 예시
tags:
  - frontmatter
---

frontmatter는 글 맨 위 `---` 두 줄 사이에 적는 글의 설정입니다. 제목, 날짜, 분류처럼 본문 밖의 정보를 여기에 적습니다.

## 가장 짧은 형태

`title`, `description`, `pubDatetime` 세 개만 있으면 됩니다. 나머지는 생략하면 기본값이 쓰입니다.

```md
---
title: 글 제목
description: 목록과 검색 결과에 보이는 한 줄 요약
pubDatetime: 2026-10-12T09:00:00+09:00
---
```

## 전체 예시

모든 항목을 다 쓰면 이렇습니다.

```md
---
title: Astro 블로그 이전기
description: Jekyll에서 Astro로 옮긴 과정
pubDatetime: 2026-10-11T09:00:00+09:00
modDatetime: 2026-10-12T21:00:00+09:00
timezone: Asia/Seoul
category: 개발/Astro
tags:
  - astro
  - migration
slug: moving-to-astro
featured: true
draft: false
ogImage: ../../assets/images/cover.png
canonicalURL: https://example.com/original-post
author: Junbeom Cho
hideEditPost: true
---
```

## 필수 항목

| 항목          | 하는 일                                                                          |
| ------------- | -------------------------------------------------------------------------------- |
| `title`       | 글 제목. 브라우저 탭, 본문 제목, 목록 카드, RSS, 자동 생성 OG 이미지에 쓰입니다. |
| `description` | 한 줄 요약. 목록 카드, 검색엔진용 설명, RSS에 쓰입니다.                          |
| `pubDatetime` | 발행일. 글의 날짜, 글 순서, 아카이브의 연·월 묶음에 쓰입니다.                    |

## 분류

| 항목       | 기본값     | 하는 일                                                                  |
| ---------- | ---------- | ------------------------------------------------------------------------ |
| `category` | `기타`     | 글이 속한 카테고리 하나. `개발/Astro`처럼 2단계까지 쓸 수 있습니다.      |
| `tags`     | `[others]` | 태그 목록. 여러 개 쓸 수 있고, 같은 태그끼리 `/tags/` 페이지에 모입니다. |

카테고리는 [카테고리 예시](/posts/category-example/)에 자세히 있습니다.

## 공개 여부와 위치

| 항목             | 하는 일                                                                     |
| ---------------- | --------------------------------------------------------------------------- |
| `draft: true`    | 글을 사이트 어디에도 내보내지 않습니다. dev 서버에서도 보이지 않습니다.     |
| `featured: true` | 홈의 **Featured** 칸에 올립니다. 대신 **Recent Posts** 목록에서는 빠집니다. |
| `slug`           | URL을 직접 정합니다. 없으면 파일명에서 날짜를 뗀 값이 URL이 됩니다.         |

`draft`는 작성 중인 글을 커밋해 두고 다른 컴퓨터에서 이어 쓸 때 유용합니다. 다만 숨겨지는 곳은 사이트뿐이라, 저장소가 공개라면 push한 초안은 GitHub에서 누구나 볼 수 있습니다. 초안도 필수 항목이 빠지거나 다른 글과 URL이 겹치면 빌드 에러가 납니다.

URL 규칙은 [파일명과 URL 예시](/posts/slug-example/)에 있습니다.

## 날짜와 시간

| 항목          | 하는 일                                                                                                                   |
| ------------- | ------------------------------------------------------------------------------------------------------------------------- |
| `pubDatetime` | 미래 시각으로 적으면 예약 글이 됩니다. 배포된 사이트에는 그 시각 15분 전부터 보이고, dev 서버에서는 바로 보입니다.        |
| `modDatetime` | 수정일. `pubDatetime`보다 나중이면 글의 날짜가 **Updated: 수정일**로 바뀌고, 글 순서와 RSS 날짜도 이 값을 따릅니다.       |
| `timezone`    | 이 글만 다른 시간대로 날짜를 표시합니다. `America/New_York` 같은 이름을 쓰고, 없으면 사이트 설정의 `Asia/Seoul`을 씁니다. |

예약 글은 정적 사이트라 저절로 나타나지 않습니다. 예약 시각이 지난 뒤 빌드가 한 번 더 돌아야 보입니다.

`timezone`은 `Asia/Seoul`, `America/New_York`처럼 정확한 이름이어야 합니다. `KST`, `UTC+9`나 오타는 빌드 에러가 납니다. 또 날짜를 표시하는 시간대만 바꿀 뿐, `+09:00` 없이 적은 날짜를 이 시간대로 읽어 주지는 않습니다.

## 이미지와 검색엔진

| 항목           | 하는 일                                                                                                   |
| -------------- | --------------------------------------------------------------------------------------------------------- |
| `ogImage`      | SNS 공유 이미지이자 목록 카드의 썸네일입니다. 글 파일 기준 상대경로 이미지나 URL을 씁니다.                |
| `canonicalURL` | 다른 곳에 먼저 올린 글을 옮겨 왔을 때, 검색엔진에 원문 주소를 알려줍니다. 없으면 이 글의 주소가 쓰입니다. |

`ogImage`가 없으면 제목으로 OG 이미지를 자동으로 만들고, 목록 카드에는 썸네일이 붙지 않습니다. [썸네일 예시](/posts/thumbnail-example/)에서 실제 모습을 볼 수 있습니다.

## 지금은 효과가 거의 없는 항목

| 항목           | 이유                                                                                               |
| -------------- | -------------------------------------------------------------------------------------------------- |
| `author`       | 자동 생성 OG 이미지에 적히는 이름만 바뀝니다. 페이지의 작성자 정보는 항상 사이트 설정 값을 씁니다. |
| `hideEditPost` | 글의 '수정하기' 링크를 숨기는 항목인데, 사이트 설정에서 그 링크 자체가 꺼져 있습니다.              |

## 주의할 점

- **없는 항목은 에러 없이 무시됩니다.** `catgory: 개발`처럼 오타를 내면 카테고리가 없는 글로 처리되어 `기타`에 들어갑니다.
- **날짜에는 따옴표를 붙이지 않습니다.** `pubDatetime: "2026-10-12"`는 문자열로 읽혀 빌드 에러가 납니다.
- **날짜에는 시간대까지 적습니다.** `2026-10-12T09:00:00`처럼 `+09:00`을 빼면 UTC로 읽혀 한국 시각으로 18시가 됩니다.
